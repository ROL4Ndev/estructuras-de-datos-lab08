# Estructuras de Datos: Pilas y Colas

Este repositorio contiene la implementacion de soluciones basadas en las estructuras de datos Lineales **Pilas (Stacks)** y **Colas (Queues)** utilizando Python y listas enlazadas.

**Alumno:** Rolando Sanchez

---

## Contenido del Repositorio

- `SanchezRolando_Ejercicio1.py`: Simulacion de un sistema de cola de impresion (FIFO) utilizando listas enlazadas.
- `SanchezRolando_Ejercicio2.py`: Sistema de atencion bancaria con dos ventanillas (una exclusiva para clientes y otra alternada) utilizando dos colas independientes.
- `SanchezRolando_Ejercicio3.py`: Editor de texto simple con funcionalidad de deshacer (Ctrl+Z) implementado con una pila (LIFO).
- `SanchezRolando_Ejercicio4.py`: Convertidor de numero decimal a binario mediante el uso de una pila.

---

## Requisitos y Ejecucion

Para ejecutar cualquiera de los ejercicios, solo necesitas Python 3 instalado.

```bash
python SanchezRolando_Ejercicio1.py
python SanchezRolando_Ejercicio2.py
python SanchezRolando_Ejercicio3.py
python SanchezRolando_Ejercicio4.py
